## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_guideline_content_checklist`** provides an interactive pre-publication and release readiness tracker for **UNIVERSE HUOKAING THARA Group**. Production teams, editors, and developers can check off verification tasks, monitor percentage completion in real time, filter by category, search items live, and inspect item notes inside a modal dialog.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **📈 Live Readiness Progress & Persistence:** Automatically calculates completion percentage and saves checked items in `localStorage` (`uht_content_checklist_v1`), complete with **Check All** and **Reset** actions.
* **🔎 Live Search & Category Filtering:** Filter items (*Media & AV, Copyright & Safety, Web & Bilingual*) or search tasks, owners, and standards in real time.
* **📝 Checklist Item Brief Modal:** View each item's ID, responsible owner, and compliance notes inside a modal window.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់

- **Frontend Core:** Semantic HTML5, CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+)
- **State Persistence:** Browser `localStorage`
- **Typography:** Google Fonts (`Kantumruy Pro` for Khmer script, `Poppins` for English UI)
- **Icons:** FontAwesome v6.4.0
- **UI/UX Design:** Cyberpunk Holographic Dark/Light Theme with Scanline Overlay
